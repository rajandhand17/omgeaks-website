# OmGeaks Brand Guidelines

## Logo assets (official — never redesign)

| Asset | File | Usage |
|-------|------|--------|
| **Brand Icon (OG)** | `/logos/omgeaks-icon.png` | Header, mobile menu, loader, favicon, scroll-to-top, app icon |
| **Full Logo** | `/logos/omgeaks-logo.png` | Footer, Contact, About only |

**Never** place the OMGEAKS wordmark beside the icon in the navigation bar.
